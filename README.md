# 🚀 LexaGhub

LexaGhub is a full-stack intelligent platform built with Django and React, designed to integrate AI capabilities into real-world applications. It provides scalable solutions for automation, data handling, and smart user interactions.

## 🔥 Features

- 🤖 AI-powered services using Transformers
- 🌐 Full-stack architecture (Django + React)
- 🔐 Secure authentication and user management
- 📊 Real-time data processing and analytics
- ⚡ Fast API communication using Axios
- 🎯 Modular and scalable design

## 🛠 Tech Stack

### Backend
- Django & Django REST Framework
- Python
- PostgreSQL / SQLite

### Frontend
- React (Vite)
- Zustand / Context API
- Axios

### AI Integration
- PyTorch
- Hugging Face Transformers
